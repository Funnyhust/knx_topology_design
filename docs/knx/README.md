# KNX Topology Documentation

This folder contains maintained KNX engineering documentation. Runtime images,
videos and historical evidence remain in the parent `docs/` folder.

## Reading map

- `desktop-build.md` — Electron portable architecture, build and smoke-test rules.

- `architecture.md` — current runtime modules, dependencies and data flow.
- `frontend-structure.md` — current and incremental target file structure.
- `knx-rules.md` — domain and business invariants.
- `ux-rules.md` — interaction and presentation invariants.
- `testing.md` — regression and verification matrix.
- `build-and-cache.md` — development/production loading and browser cache rules.
- `decisions.md` — active architecture and product decisions.

The detailed historical UI specification remains at
`docs/ui-interaction-spec.md`. Where it describes superseded auto-placement or
auto-wiring behaviour, the decisions in this folder take precedence.
